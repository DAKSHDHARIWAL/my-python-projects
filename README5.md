
📌 Task 5: Data Scraper
 🔹 Description:
A web scraping program that extracts book titles and prices from a website and saves them into a CSV file.

 🔹 Features:
 Uses `requests` to fetch webpage content
 Uses `BeautifulSoup` to parse HTML
Extracts book titles and prices
Converts prices into INR (₹)
 Saves data into a CSV file
